# Port Marlowe

Port Marlowe is an original third-person open-world game set in a coastal city. You play two
partners, and the police respond only to what witnesses report. It is built in **Unity 6000.6.5f1**
with URP. The target is Xbox Series X in Developer Mode (UWP); development happens on desktop.

> **Status:** the first playable milestone is implemented. Its rules are unit-tested and all of its
> code compiles against the real Unity 6000.6.5f1 APIs. It has **not yet run in the Unity editor,
> on a desktop player, or on Xbox**, and **no installable package exists yet**.
> See [`Docs/STATUS.md`](Docs/STATUS.md) for the evidence and the blockers.

## Repository layout

| Path | Contents |
| --- | --- |
| `Assets/PortMarlowe/Runtime/Core` | Engine-independent simulation rules (crime, police, seats, switching, partner AI, saves, economy, district plan) |
| `Assets/PortMarlowe/Runtime/Game` | Unity adapters: world build, characters, vehicles, population, police, safehouse, UI, lighting, diagnostics, bootstrap |
| `Assets/PortMarlowe/Rendering/Urp` | URP render backend and its project-setup step |
| `Assets/PortMarlowe/Editor` | Project setup, build tool, texture import rules |
| `Assets/PortMarlowe/Tests` | EditMode tests (core rules) and PlayMode smoke tests |
| `Tools/CoreTests` | Builds the core library and runs its tests on plain .NET (no Unity licence needed) |
| `Tools/UnityCompileCheck` | Compiles every assembly against the real Unity assemblies, without running the editor |
| `Tools/Assets` | CC0 surface discovery and pinned fetch (Poly Haven, ambientCG) |
| `Docs/` | Status, build and deploy guide, Xbox checklist, subsystem ledger, decisions, art bible, asset manifest |

## Quick start

1. Open the project in Unity 6000.6.5f1.
2. Run **Port Marlowe ▸ Run Project Setup**.
3. Open `Assets/PortMarlowe/Scenes/Boot.unity` and press Play.

Optional: run `python3 Tools/Assets/fetch_cc0.py` first (needs Pillow and network access) to get the
real PBR street surfaces.

Builds, the automated smoke run and UWP packaging are covered in
[`Docs/BuildAndDeploy.md`](Docs/BuildAndDeploy.md).

## Controls (Xbox controller)

| Input | Action |
| --- | --- |
| Left stick | Move or steer |
| Right stick | Camera |
| A | Sprint (hold) |
| Y | Enter or exit vehicle |
| X | Interact (doors, bed, wardrobe) |
| B | Strike / shove |
| RT / LT | Throttle / brake and reverse |
| RB | Handbrake |
| L-stick click | Horn |
| R-stick click | Swap camera shoulder |
| D-pad down | Switch character |
| D-pad up | Partner: follow or hold |
| View | Diagnostics overlay |
| Menu | Pause |

The keyboard and mouse bindings are for desktop development only. The in-game **Controls** page is
the authoritative list (`GameInput.ControllerMap`).

## Licensing of content

All current art and audio is generated by project code. Optional CC0 surfaces are fetched by a
pinned script rather than committed. The reference images from the project pack are kept outside
